A full-stack sentiment analysis platform for Indonesian-language customer reviews of **Traveloka** and **Agoda**. It covers the whole path from raw reviews to a working web app: data collection, cleaning and labeling, text preprocessing, two machine-learning models, and a Flask service with a login-protected dashboard.

## What it does

- Classifies **5,000+ collected reviews** with two models side by side: a **Support Vector Machine (SVM)** and **Gaussian Naive Bayes**.
- Returns a sentiment label (Negatif / Netral / Positif) with a confidence score from each model, plus a preview of the cleaned text the models actually saw.
- Takes a single review typed into the app, or a **CSV file** of reviews, and shows the results in a dashboard.

## How it works

1. **Collect.** Custom scraping pipelines gather the reviews, then clean and label them into a training set.
2. **Preprocess.** Indonesian-specific cleaning: lowercase, strip URLs, @mentions, hashtags, punctuation and numbers, then **Sastrawi** stopword removal and stemming. Class balancing keeps training robust and less biased toward the majority class.
3. **Vectorize.** **TF-IDF** turns each cleaned review into a feature vector.
4. **Classify.** Both models score every review. Gaussian Naive Bayes needs a dense matrix, so the sparse TF-IDF vectors are converted for that model only.
5. **Serve.** A Flask REST API exposes the models; the trained models and vectorizer are loaded once at startup instead of on every request.

## Architecture

Scraping, preprocessing, inference, and the UI are separate layers, so a new model can be added without touching the rest.

| Endpoint | Purpose |
| --- | --- |
| `POST /predict` | Classify a single review |
| `POST /upload` | Classify a CSV file of reviews |
| `GET /health` | Health check |
| `GET /dashboard` | Results view (login required) |

The interface is a responsive HTML and Bootstrap frontend with session-based login, file upload, and result history kept in the browser with `localStorage`.

## Stack

Python, Flask, TF-IDF, SVM, Gaussian Naive Bayes, Sastrawi (Indonesian NLP), HTML and Bootstrap.
